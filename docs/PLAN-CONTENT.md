# 衝 — 추가 콘텐츠 기획 (v0.5 계획안)

작성 2026-11-27. 핵심 게임(충돌 체스·光 모드·실험 노트)이 완성된 뒤, **"한 판 더"와 "내일 또"**를 만드는 콘텐츠 계획. 구현 전 검토용.

---

## 0. 원칙

1. **물리가 곧 보상이다.** 보상은 숫자가 아니라 *내가 일으킨 물리 현상*(사진·식·발견)이어야 한다. 衝만의 동기.
2. **실력이 진행이다.** 성장 수치·과금·가챠·운 요소 없음 (마스터스펙 불변 조건). 해금은 실력과 발견으로만.
3. **서버 없이.** 전부 정적 사이트 + localStorage + 링크 공유로 동작 (GitHub Pages 유지).
4. **탐구와 연결.** 플레이 기록이 곧 「역학과 에너지」 탐구 데이터가 되도록.

## 1. 동기 루프

```
 대국 / 퍼즐 ──▶ 충돌이 일어난다 ──▶ 스트로보 사진으로 박제
     ▲                                   │
     │                                   ▼
 새 실험 조건 해금 ◀── 연구원 등급 상승 ◀── 현상 도감에 등록 (발견!)
     │
     └──▶ 연구 일지(캠페인)의 다음 장 / 오늘의 실험
```

짧은 루프(1판 5–15분): 충돌 → 사진 → 도감 칸이 채워짐.
중간 루프(하루): 오늘의 실험(퍼즐 1 + 조건부 대국 1), 연속 기록.
긴 루프(몇 주): 연구 일지 7장 완주, 도감 완성, 등급 「노벨상」.

## 2. 콘텐츠 목록

### A. 당구 문제 (충돌 퍼즐) — ★ 1순위
| 항목 | 내용 |
|---|---|
| 형식 | "한 수로 ○○하라": 기물 2개 동시 낙하, 뉴턴의 요람으로 킹 떨어뜨리기, n수 메이트, 광속 한계를 이용한 수, 자폭(오버슈트) 피하기 |
| 별 3개 규칙 | ★ 풀기 · ★★ 첫 시도에 · ★★★ **조준 판서 없이** — 조준 판서(미리보기)가 곧 힌트 자원이 된다 |
| 생성 | AI 자가대국에서 "한 수에 ≥2개 낙하 / 강제 메이트" 국면을 자동 채굴 → 엔진으로 유일해 검증 → 난이도 = 탐색 깊이·후보 수. 100+개 |
| 테마 묶음 | 「탄성」「요람」「반동」「낙하」「광속」 5개 세트, 세트마다 15–20문제 |
| 기술 | `tools/mine-puzzles.ts` + 퍼즐 JSON + 검증 테스트 (해답 유일성) |

### B. 현상 도감 (발견 수집) — ★ 1순위
게임 중 엔진이 사건을 감지하면 도감에 등록되고, **그 순간의 스트로보 사진**이 그 칸의 그림이 된다.

| 현상 | 감지 조건 (엔진 이벤트) | 배우는 것 |
|---|---|---|
| 뉴턴의 요람 | 같은 질량 3연쇄 이상 | 속도 교환 |
| 반동 | 공격자 속도 < 0 | 가벼운→무거운 |
| 오버슈트 | 공격자 자신이 낙하 | 운동량의 대가 |
| 이중 낙하 / 삼중 낙하 | 한 충돌에 2·3개 제거 | 연쇄 설계 |
| 광속의 벽 | 대상 속도 ≥ 0.9c | 상대론적 포화 |
| γ 1.5 | 도움닫기 γ ≥ 1.5 | 로런츠 인자 |
| 뉴턴은 틀렸다 | 뉴턴 계산이면 낙하인데 실제로는 생존 | 고전역학의 한계 |
| 열 | 나이트 낙하 3회 | 비탄성 충돌 |
| 낭떠러지 메이트 | 연쇄 충돌로 메이트 | — |
| 보이지 않는 기물 | 光 모드에서 안개 사격 적중 | 지연 관측 |
| …총 24칸 | | |

각 칸: 사진 + 식(예: `v₂' = 2m₁/(m₁+m₂)·v`) + 한 줄 설명. **탐구 보고서의 사례 모음이 저절로 쌓인다.**

### C. 스트로보 사진 (포토 모드 / 공유) — ★ 1순위
- 충돌이 끝나면 하단에 작은 "📷" — 누르면 그 충돌을 **다중 섬광 사진 한 장**으로 렌더(정지 시점, 잔상 전부, 분필 식, 날짜·수 번호·서명 `衝`).
- 경기 종료 화면에 「오늘의 결정적 순간」 자동 선정(가장 큰 충격량의 충돌).
- PNG 저장 / 링크 공유. 衝의 시그니처 비주얼이 그대로 홍보물이 된다.

### D. 연구원 등급 (AI 사다리)
`학부생 → 석사 → 박사 → 박사후 → 교수 → 노벨상` — AI 난이도·조건별 승리로 상승 (로컬 저장). 등급마다 칭호와 칠판 서명이 바뀐다. 숫자 레이팅 대신 서사.

### E. 연구 일지 (캠페인) — ★ 2순위, 가장 큰 콘텐츠
7장, 장마다 **물리 법칙 하나를 바꾼 실험 조건**에서 AI와 대국. 승리하면 그 조건이 「실험 조건 카드」로 해금되어 자유 대국·오늘의 실험에서 쓸 수 있다.

| 장 | 실험 조건 | 규칙 변화 | 전략이 어떻게 바뀌나 |
|---|---|---|---|
| 1 | 완전 탄성 | 기본 衝 | 기본기 |
| 2 | 반발계수 e = 0.6 | 충돌마다 에너지 손실 | 연쇄가 짧아진다, 근접전 |
| 3 | 빙판 칸 | 일부 칸은 마찰 0 — 멈추지 않고 미끄러진다 | 지형 읽기 |
| 4 | 경사판 | 보드가 한쪽으로 기울어 정지 기물도 서서히 밀린다(중력) | 고지대 확보 |
| 5 | 무거운 폰 | 질량표 변경(폰 3) | 폰 벽의 부활 |
| 6 | 느린 빛 | c = 2.5 칸/턴 | 상대론적 효과 극대화 |
| 7 | 光 | 지연 시야 + 위 조건 중 2개 | 종합 |

장 사이: 「실험 노트」 POE 한 쪽으로 새 조건을 먼저 예측해 보게 한다.
기술: 물리 상수(질량표·c·e·마찰장·중력 벡터)를 `Physics` 설정 객체로 파라미터화 — 엔진 테스트 그대로 재사용.

### F. 오늘의 실험 (데일리)
날짜 시드 → 퍼즐 1개 + "오늘의 조건"(E의 카드 1장) 대국 1판. 연속 기록(로컬). 결과를 이모지 격자 텍스트로 공유:
```
衝 오늘의 실험 #142  ★★☆
🟦🟦⬛🟥  3수 · 이중 낙하
```

### G. 편지 대국 (비동기 PvP, 서버 없음)
게임 상태(초기 조건 + 수 목록)를 URL 해시에 인코딩. 한 수 두면 새 링크 생성 → 메신저로 상대에게 보내기. 光 모드는 각자 자기 시야만 보이므로 정보 은닉이 지켜진다(상대 수는 링크 안에 암호화 없이 들어가므로 "신사 협정" 표기). 같은 기기 2인 대국(핫시트)도 함께.

### H. 실험실 LAB (샌드박스 · 탐구용)
자유 배치, 질량·c·e 조정, 충돌 실행, Σp·ΣE 시간 그래프, CSV 내보내기, 뉴턴 vs 상대론 비교 버튼. 만든 배치를 퍼즐 링크로 공유(사용자 제작 퍼즐).

### I. 외형 해금 (실력으로만)
보드 테마: 밤의 실험실 / 1905 특허청 / 진공 챔버(무중력 연출). 분필 색, 스트로보 색. 도감·등급으로만 해금. 판매 없음.

## 3. 우선순위와 단계

| 단계 | 내용 | 이유 | 규모 |
|---|---|---|---|
| **P1** | A 당구 문제 + C 사진 + B 도감 (v0.5: A·B 완료, C 남음) | 가장 짧은 루프, 衝만의 정체성, 엔진 재사용 | 중 |
| **P2** | F 오늘의 실험 + D 등급 | 재방문 동기, P1 콘텐츠 재활용 | 소 |
| **P3** | E 연구 일지 (물리 파라미터화 포함) | 가장 큰 깊이, 엔진 확장 필요 | 대 |
| **P4** | H 실험실 · G 편지 대국 · I 외형 | 탐구·공유·장기 | 중 |

## 4. 기술 선행 작업
- `Physics` 설정 객체: 질량표, c, 가속도, 반발계수 e, 칸별 마찰, 중력 → `simulateLine`/`make`가 받도록 (현재 상수).
- 결정론적 시드 RNG를 앱 전역에 (데일리·퍼즐·리플레이 공유).
- 저장소: 버전 있는 localStorage 스키마 (`chung:v1:*`), 손상 시 안전 초기화.
- 사진: 렌더 타깃 → 2D 캔버스 합성(분필 레이어·텍스트) → `toBlob`.
- URL 코덱: FEN + UCI 수 목록 → base64url.
- 사건 감지기: 충돌 결과(`Outcome`)에서 현상 판정 — 순수 함수 + 테스트.

## 5. 측정 (탐구와 겸용)
퍼즐 정답률·조준 판서 사용률·도감 완성률·평균 판 길이를 로컬 통계로 저장, 「기록 내보내기」(JSON/CSV). 사람 플레이테스트로 재미 검증 — 봇 결과는 재미의 증거가 아니다.
